<h2>Overview</h2>
This project is a menu-driven Python program that allows users to interact with 4 core functionalities:

- GPA Calculator – Uses Student and Course classes to calculate and display a student’s GPA based on input courses, credits, and letter grades.

- Lottery Number Generator – Generates Powerball-style lottery numbers with no repeats.

- Pig Latin Converter – Converts user-entered sentences into Pig Latin.

- Rock-Paper-Scissors Game – Allows the user to play against the computer with randomized choices.
